# 🧠 وازن (Wazen) - Project Context

هذا الملف هو **المرجع التقني الأول (Knowledge Base)** ومقرر أن يقرأه أي ذكاء اصطناعي (Agent) أو مطور جديد قبل كتابة أي كود أو اقتراح تعديلات في المشروع.

## هدف المشروع (Project Goals)

بناء تطبيق "وازن" لإدارة المصاريف والميزانيات التشاركية، وهو تطبيق لسد الفجوة بين تطبيقات المصاريف الشخصية البسيطة والبرامج المحاسبية المعقدة.
يستهدف التطبيق:

1. **وازن عائلي (Wazen Home)** 🏠: للأزواج والشركاء لإدارة مصروفات المنزل والرحلات العائلية بشفافية.
2. **وازن أعمال (Wazen Biz)** 💼: لإدارة العهد المالية لمشرفي المواقع ومطابقة فواتير الشركات الصغيرة.

### الأهداف الحالية:

- نظام إدارة المصادقة والأدوار (Owner, Partner).
- الصناديق المالية المشتركة (Prepaid Joint Funds) وضخ التمويل فيها.
- إدارة طلبات الشراء (Shopping Orders) واعتمادها المباشر من المالك.
- لوحة تحكم تفاعلية مع الوضع الداكن والتحليلات.

---

## التقنيات المعتمدة (Tech Stack)

هذه التقنيات ثابتة وتم اتخاذ قرارات بشأنها، لا تقم باقتراح تغييرها:

- **إطار العمل (Framework):** React v18 + Vite (لضمان أداء فائق وتصميم فاخر).
- **الخلفية والمحرك (Backend):** Node.js + Express.
- **قاعدة البيانات (Database):** PostgreSQL / SQLite مدارة بواسطة Prisma ORM.
- **التصميم (Styling):** Vanilla CSS + Tailwind CSS (تصميم زجاجي Glassmorphism فاخر).
- **التدويل (i18n):** React-i18next مع دعم كامل للغة العربية (RTL).

## خريطة الطريق الحالية (Current Roadmap)

### ما تم إنجازه (Completed ✅)

- إعداد بيئة التطبيق الأمامية والخلفية بالكامل.
- تحديث مخطط قاعدة البيانات (Prisma DB Schema) ودعم العلاقات المحدثة.
- بناء وحفظ الهوية البصرية وشعار التطبيق (Vector SVG + Mockups).
- تفعيل خدمات وصمامات الأمان في الخلفية (Access Control, Private Categories).
- بناء لوحة التحكم ومستعرض الصناديق والطلبيات المشتركة.

### ما سيتم إنجازه (Future Horizon)

- كبسولات الاختيار السريع للعمليات المتكررة (Quick Selection Chips).
- الفلترة المتقدمة لبيانات المالك (شخصي vs مشترك).
- محرك تصدير البيانات إلى جداول Excel/CSV.

## قاموس المصطلحات الصارم (Strict Terminology Rule)

للمحافظة على سلامة البيانات، التزم بالمصطلحات التالية:

1. **المالك** (Owner): مالك الحساب والمسؤول المالي الأول.
2. **الشريك** (Partner): شريك الصرف أو أمين العهدة المرتبط بحساب المالك عبر `parentId`.
3. **الصندوق المشترك** (Joint Fund): صندوق العهدة أو مصروف البيت.
4. **طلبية الشراء** (Shopping Order): طلب شراء معلق يرفعه الشريك ويحتاج موافقة المالك.
5. **المعاملة المالية** (Transaction): حركة صرف أو وارد مسجلة.
6. **الميزانية** (Budget): التقدير المالي الشهري لفئة معينة.
