## 🎯 1. نظرة عامة معمارية (Architecture Overview)

- **النوع:** تطبيق ميزانية تشاركية وإدارة عهد مالية (B2B Lite / Family Sharing).
- **النمط الهندسي:** Monolith (Express backend + Vite React SPA).
- **الواجهة الأمامية (Frontend):** React 18 + Vite + Tailwind CSS.
- **التصميم (UI/UX):** Glassmorphism فاخر، يدعم الوضعين الفاتح والداكن، وتصميم مخصص للهاتف أولاً لسهولة إدخال البيانات ميدانياً.
- **الخلفية وقاعدة البيانات (Backend & DB):** Node.js Express + Prisma ORM + PostgreSQL/SQLite.

---

## ✅ 2. الوضع الحالي والميزات المنجزة (Current State)

1. **قاعدة البيانات ومخطط Prisma:**
   - تم تصميم جداول قاعدة البيانات بالكامل (`User`, `JointFund`, `Category`, `Transaction`, `ShoppingOrder`, `Budget`).
   - تم تعديل العلاقات بنجاح لمنع تعارضات Prisma وحظر الفئات الحساسة للمالك عن حسابه الفرعي (الشريك).

2. **المصادقة والصلاحيات (Auth & RBAC):**
   - تم بناء نظام تسجيل دخول ومصادقة معتمد على الأدوار (Owner و Partner).
   - الشريك مرتبط بحساب المالك الرئيسي عبر حقل `parentId`.

3. **الصرف التشاركي والصناديق المشتركة (Prepaid Joint Funds):**
   - يمكن للمالك ضخ الأموال إلى صندوق مشترك متاح للشريك.
   - الشريك يمكنه تسجيل مصروفات من الصندوق المشترك لتخصم من رصيده مباشرة.
   - يمكن للشريك رفع "طلب شراء" (Shopping Order)، وعند قيام المالك بالموافقة عليه يتم تحويله لمعاملة فورية.

4. **البيئة والبناء:**
   - المشروع جاهز للبناء محلياً للإنتاج عبر `npm run build`.

## 🧭 3. الأهداف القادمة للوكيل (Next Agent Tasks)

وفقاً لخطة العمل، المهام التالية مطلوبة:

1. **تنظيف الأكواد الميتة (Dead Code Cleanup)**: حذف شاشات Mui القديمة ومكوناتها تماماً لتجنب أي تشتت.
2. **تحسين أداء الوضع الداكن (Dark Mode Refactoring)**:
   - منع الوميض الأبيض المزعج عند تحميل الصفحات.
   - جعل الزر مركزياً في القائمة الجانبية.
3. **ميزات إدخال الصرف السريعة**: إضافة كبسولات الاختيار السريع (Selection Chips).
4. **الفلترة والتصدير**: إتاحة فلترة الخصوصية وتصدير البيانات.

## ⚠️ 4. تحذيرات هندسية للـ Agent (Red Flags)

- **أمن عمليات الحذف والتعديل**: تحقق دائماً من ملكية المستخدم للمعاملة، وتأكد من أن المالك الرئيسي فقط هو من يمكنه تعديل/حذف معاملات الشريك.
- **عزل بيانات الذكاء الاصطناعي**: تأكد من عدم خلط بيانات المالك الخاصة والشخصية بأي معلومات تظهر للشريك أو تدخل في تحليل الشريك.
- **تجنب المكتبات الضخمة غير الضرورية**: التزم بـ Vanilla CSS و Tailwind CSS مع Cairo Font لتنسيق الواجهات الفاخرة.
