# 0001: الاعتماد على Next.js App Router

**التاريخ:** إبريل 2026  
**الحالة:** معتمد (Accepted)

## السياق (Context)
مشروع "الرفيق المدرسي" هو نظام مؤسسي ضخم (Enterprise System) سيحتوي على لوحات تحكم متعددة (معلم، طالب، ولي أمر، إدارة). كان الخيار مطروحاً بين استخدام React النقي (Vite) أو إطار عمل كامل، وبين Pages Router الكلاسيكي و App Router الجديد في Next.js.

## القرار (Decision)
قررنا استخدام **Next.js إصدار 16 فما فوق** معمارية **App Router**.

## المبررات (Rationale)
1. **أداء ممتاز:** بفضل Server Components سيتم إرسال محتوى أقل للمتصفح (JavaScript أقل) مما يوفر أداء عالياً للأجهزة الضعيفة.
2. **التوجيه المتداخل (Nested Routing):** يسمح App Router ببناء تخطيطات (Layouts) معقدة بسهولة، وهو ما نحتاجه في لوحات التحكم، لتثبيت القوائم الجانبية (Sidebar) وإعادة تحميل المحتوى فقط.
3. **أمان البيانات:** جلب البيانات وتأكيد الصلاحيات (Authorization) يمكن أن يتم مباشرة في السيرفر قبل وصول الصفحة للمستخدم.

## العواقب (Consequences)
- منحنى تعلم مختلف لأي مطور معتاد على Pages Router أو React النقي.
- لا بد من الانتباه الدائم لنوع المكون (`"use client"` مقابل Server Component).
