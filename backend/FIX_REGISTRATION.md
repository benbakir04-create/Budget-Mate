# حل مشكلة "المستخدم موجود بالفعل"

## 🔍 المشكلة

عند محاولة التسجيل لأول مرة، تظهر رسالة "المستخدم موجود بالفعل" أو "User already exists".

## ✅ الحلول

### الحل 1: استخدام بريد إلكتروني مختلف (الأسهل)

ببساطة استخدم بريد إلكتروني مختلف عند التسجيل:

**أمثلة:**

- `ahmed@test.com`
- `mohammed@example.com`
- `user1@demo.com`
- `test2@test.com`

---

### الحل 2: حذف جميع المستخدمين من قاعدة البيانات

إذا أردت حذف جميع المستخدمين المسجلين مسبقاً:

#### الطريقة 1: استخدام السكريبت الجاهز

```bash
cd backend
npm run clear:users
```

#### الطريقة 2: استخدام Prisma Studio (واجهة رسومية)

```bash
cd backend
npx prisma studio
```

ثم:

1. افتح جدول `User`
2. احذف المستخدمين يدوياً

#### الطريقة 3: إعادة تعيين قاعدة البيانات بالكامل

⚠️ **تحذير:** هذا سيحذف جميع البيانات!

```bash
cd backend
npx prisma migrate reset
npm run prisma:seed
```

---

### الحل 3: التحقق من المستخدمين الموجودين

يمكنك التحقق من المستخدمين الموجودين باستخدام Prisma Studio:

```bash
cd backend
npx prisma studio
```

ثم افتح جدول `User` لرؤية جميع المستخدمين المسجلين.

---

## 🎯 الحل السريع الموصى به

**الأسهل والأسرع:** استخدم بريد إلكتروني مختلف:

```
الاسم: أحمد محمد
البريد الإلكتروني: ahmed123@test.com  (غير البريد)
كلمة المرور: password123
تأكيد كلمة المرور: password123
```

---

## 📝 ملاحظات

1. **البريد الإلكتروني فريد:** لا يمكن استخدام نفس البريد مرتين
2. **البريد لا يحتاج أن يكون حقيقياً:** يمكنك استخدام أي بريد بصيغة صحيحة
3. **حذف المستخدمين:** سيحذف أيضاً جميع البيانات المرتبطة (المعاملات، الميزانيات، إلخ)

---

## 🆘 إذا استمرت المشكلة

1. تأكد من أن الباكند يعمل: `cd backend && npm run dev`
2. تحقق من console المتصفح (F12) لرؤية رسالة الخطأ الدقيقة
3. تأكد من أن قاعدة البيانات متصلة بشكل صحيح
