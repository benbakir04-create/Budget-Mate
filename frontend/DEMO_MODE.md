# وضع Demo - النسخة التجريبية

## 🎯 ما هو وضع Demo؟

وضع Demo يسمح للمستخدمين بتجربة التطبيق **بدون الحاجة لتسجيل حساب**. هذا مفيد للعروض التوضيحية والتجربة السريعة.

## ✅ المميزات

- ✅ **دخول مباشر**: لا حاجة لتسجيل الدخول
- ✅ **مستخدم تجريبي افتراضي**: يتم إنشاء مستخدم تجريبي تلقائياً
- ✅ **تجربة كاملة**: يمكن تجربة جميع الميزات
- ✅ **سهولة الوصول**: افتح التطبيق مباشرة وابدأ الاستخدام

## 🚀 كيفية الاستخدام

### الوضع الافتراضي (Demo مفعّل)

ببساطة افتح التطبيق:

```
http://localhost:5173
```

سيتم توجيهك مباشرة إلى Dashboard بدون الحاجة لتسجيل الدخول.

---

## ⚙️ الإعدادات

### تفعيل/تعطيل Demo Mode

في ملف `frontend/src/contexts/AuthContext.jsx`:

```javascript
// تفعيل Demo mode
const DEMO_MODE = true;

// تعطيل Demo mode (يتطلب تسجيل دخول)
const DEMO_MODE = false;
```

أو يمكنك استخدام متغير البيئة في ملف `.env`:

```env
VITE_DEMO_MODE=true
```

---

## 🔄 الانتقال من Demo إلى حساب حقيقي

إذا كنت في وضع Demo وأردت إنشاء حساب حقيقي:

1. اضغط على رابط "إنشاء حساب حقيقي" في إشعار Demo
2. أو اذهب مباشرة إلى: `http://localhost:5173/register`
3. سجّل حسابك الجديد
4. سيتم تسجيل خروجك من Demo تلقائياً

## ⚠️ ملاحظات مهمة

1. **البيانات في Demo**: البيانات التي تضيفها في وضع Demo قد لا تُحفظ بشكل دائم
2. **الخروج**: يمكنك الخروج من Demo والانتقال لتسجيل الدخول الحقيقي في أي وقت
3. **التطوير**: في مرحلة التطوير، Demo mode مفعّل افتراضياً

## 🛠️ للمطورين

### إضافة ميزات Demo Mode

إذا أردت إضافة ميزات خاصة بوضع Demo:

```javascript
import { useAuth } from '../contexts/AuthContext';

const MyComponent = () => {
  const { isDemoMode, user } = useAuth();

  if (isDemoMode) {
    // كود خاص بوضع Demo
  }

  // باقي الكود
};
```
